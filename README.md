# Gravity Moments — сайт

Односторінковий сайт без збірки й залежностей: один `index.html`, усередині
стилі та скрипти. Щоб щось змінити, достатньо відкрити його текстовим редактором.

---

## Що де лежить

| Файл / тека | Що в ньому |
|---|---|
| `index.html` | Уся сторінка: тексти, секції, стилі, скрипти |
| `img/s/` | Атмосферні фото (стоки Unsplash), `t_*` — зменшені копії для сітки |
| `img/ev/` | Реальні кадри MedOrion Awards, `t*` — зменшені |
| `img/marina*.jpg` | Фото Марини |
| `video/` | Вертикальні ролики та кадри-постери до них |
| `demo.js` | Захист від копіювання (без водяних знаків) |
| `telegram-worker/` | Приймач заявок у Cloudflare. **Наразі не підключений** |

---

## Як замінити фото

Покладіть новий файл у `img/` і впишіть його імʼя в `index.html`.
Для сітки галереї потрібні дві копії: повна і зменшена з префіксом `t`.

Галерея зібрана з чотирьох форматів — весілля, гендер-паті, новорічні
корпоративи, премії. Кожна картка відкриває добірку: шукайте `class="ev-cards"`
і далі блок `gm-hidden` зі списком кадрів цього формату.

---

## Зірки

Секція `id="stars"` — плитки з іменами артистів. Щоб додати нове імʼя,
скопіюйте блок `<article class="gm-star …">` і змініть текст.
Класи `a`, `b`, `c`, `d` відповідають за колір плитки.

**Імена мають бути реальні.** Обіцянка «у нас є зірки» без підтвердження
працює проти нас.

---

## Заявка

Форма в модальному вікні збирає відповіді й відкриває WhatsApp Марини
з готовим текстом. Телеграм-воркер зі старої версії лишився в теці
`telegram-worker/`, але адреса `gravity-form.workers.dev` не відповідає —
якщо його підняти, треба замінити виклик у кінці `index.html`.

---

## Цін на сайті немає

Жодних сум, вилок і калькуляторів — свідомо. Сайт продає рівень і доступ
до артистів, а цифри називаються в розмові.
